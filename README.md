## 📌 About The Project

Solar System Animation is a visual web project built using HTML and CSS. It simulates the orbital movements of the Sun, Earth, and Moon using CSS animations. The Earth revolves around the Sun, while the Moon revolves around the Earth, creating a simple animated representation of the solar system.

## ✨ Features

- Display the Sun, Earth, and Moon.
- Animate the Earth's orbit around the Sun.
- Animate the Moon's orbit around the Earth.
- Create smooth and continuous orbital movements.
- Add a glowing effect to the Sun using CSS.
- Use circular orbital paths.
- Simple and visually appealing design.
- No JavaScript required.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Animations
- CSS Keyframes
- CSS Positioning
- CSS Transforms
- CSS Pseudo-elements

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Watch the Sun, Earth, and Moon animations.

- Using `transform` and `rotate()`.
- Applying `animation-duration`, `animation-timing-function`, and `animation-iteration-count`.
- Working with CSS pseudo-elements (`::before`).
- Creating glowing effects using `box-shadow`.
- Building animated visual elements using pure CSS without JavaScript.
